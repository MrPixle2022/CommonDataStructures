# Common DS in C

this is a repo where i attempt to recreate common data-structures in C from scratch, mostly the managing of each DS is done via functions, the functions naming will follow a template being `{ds_name}_{function}` and each function will take a pointer to the target DS as it's first arguments, i will also try to add docs to each ana every function and datatype to ensure that nothing is ambagious

---

## Vectors

for the dynamic arrays -aka Vectors- i must introduce an easy way to initialize, manage and release the vector, i must ensure no memory leakage, no dangling pointers, and as much versatility as i can possibly add.

---

## Singly-linked list

very similar to the dynamic array, except this time each node points to the next one, depending on how much utility functions i am willing to define this may prove exhausting or annoying, hell even both, only time will tell
